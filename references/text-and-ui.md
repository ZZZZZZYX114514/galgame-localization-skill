# 文本、选项与图片按钮

## 提取与翻译

按脚本引用和命令类型统计正文、人物名、选项、系统提示和菜单标签。保留位置与原文，让重复短句仍能按上下文分别处理。格式不明的命令保留原字节，记录为后续分析对象。

选项可能存放在脚本数组、配置文件、独立资源或图片中。找到引用后记录每个选项的显示文字、选项索引和分支目标。只修改显示字段，并比较跳转字段与命令顺序。

建立人物称呼、地名和界面术语表。批量翻译时保留控制码、变量与占位符，避免将命令标签作为自然语言翻译。对分支条件、否定句、代词、短选项与长句溢出做针对性复核。

内容完成量按实际提取与检查的记录计数。正文、选项和按钮分别报告覆盖情况，检查失败的条目留在清单中。

## 字体与排版

确认实际使用的字体、字符集、字号、文本矩形和自动换行规则。对姓名框、选项、多行说明和存档标题分别测量中文宽度。优先沿用游戏布局，依据按钮可用区域选择简短译名。

字体文件若需要随补丁分发，核对其授权并附上所需许可。系统字体可在本机用于绘制已经栅格化的标签，目标设备依赖的运行时字体另行验证。

## UI 资源定位

先用配置中的资源名、帧坐标、大小和脚本引用确认按钮。相同按钮可能包含普通、悬停、按下、选中和禁用状态，也可能拆成底图与透明蒙版。

对本轮修改建立资源清单，记录文件名、原始哈希、尺寸、像素格式、文字矩形、各状态对应位置以及蒙版布局。位置确定后再检查文字区域。

当用户禁止读取某类图片时，资源访问范围以其要求为准。设置面板可能嵌有场景预览，缩略图集合也可能包含被限制资源。无法证明为纯文字区域的素材，可先根据配置和引用完成定位及尺寸分析。

## 限定区域预览

`crop_bmp_region.py` 支持未压缩的 24 位 BGR 或 32 位 BGRA Windows BMP，坐标为左上角起算的半开区间。脚本只读取 BMP 头和选中矩形的像素行。需要 Pillow，安装与版本使用当前环境已有依赖或按任务需要准备。

```powershell
python scripts/crop_bmp_region.py "C:/work/menu.bmp" "C:/work/label.png" --box 20 30 180 70
```

`--alpha` 接收无文件头、左上至右下排列、每像素一字节的外部蒙版，大小须等于原图宽乘高。引擎 `.alp` 可能有其他编码，先验证样本布局。32 位工具路径按 BGRA 解释透明度，需要确认第四字节的语义。

## 重绘与写回

在完整原资源的副本上清除指定文字矩形，使用已确认字体绘制译文。保留尺寸、格式、坐标与各状态。透明资源需要同步更新文字区域对应的蒙版，并将区域外的像素和蒙版字节与原版比较。

按钮含图标、渐变底图或场景预览时，文字清除方法需依据该矩形的实际构造确定。对已知纯色文字底板可填色后重绘，对复杂底板可使用游戏已有的空白状态或已验证的背景恢复方式。

先写入少量按钮并在游戏中检查点击区域、各状态和中文裁切。通过后按同一格式批量处理，记录每个资源的变更哈希。打包阶段沿用 [NekoSDK 格式](nekosdk.md) 中的未修改条目保留方式。
